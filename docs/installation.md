# Installation

## Stable release

To install aiocop, run this command in your terminal:

```sh
uv add aiocop
```

Or if you prefer to use `pip`:

```sh
pip install aiocop
```

## From source

The source files for aiocop can be downloaded from the [Github repo](https://github.com/Feverup/aiocop).

You can either clone the public repository:

```sh
git clone git://github.com/Feverup/aiocop
```

Or download the [tarball](https://github.com/Feverup/aiocop/tarball/master):

```sh
curl -OJL https://github.com/Feverup/aiocop/tarball/master
```

Once you have a copy of the source, you can install it with:

```sh
cd aiocop
uv pip install .
```
